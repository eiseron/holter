# Configurações de Usuário

Abra suas configurações de Usuário pela entrada **Minha conta** na barra lateral do workspace. A página fica em `/identity/user/{user-id}` — só você pode abrir a sua própria, e ela independe do workspace que você esteja visitando.

A página também lista todos os workspaces a que você pertence. Clique em um workspace cujo papel é `Owner` ou `Admin` para abrir as [Configurações do Workspace](workspace.md).

## Idioma

O campo **Idioma** controla o idioma da UI para *sua* conta, independente do workspace que você esteja visitando.

- Escolha **Português (Brasil)** ou **Inglês** para sobrescrever qualquer outra fonte.
- Escolha **Usar padrão do workspace** (a opção vazia) para cair no idioma padrão do workspace. Se ele também não estiver definido, o cabeçalho `Accept-Language` do navegador é usado; por último, o Holter cai no Português brasileiro.

Clique em **Salvar** e a página recarrega já no novo idioma. Pra voltar ao padrão do workspace depois, abra esta página de novo, escolha a opção vazia e Salvar.
